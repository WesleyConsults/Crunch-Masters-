# CrunchMasters | Premium Culinary Experience

CrunchMasters is a premium food service application designed for the KNUST community. It features a modern, artisanal menu, a seamless ordering system, and a robust partner/admin dashboard for managing operations.

## Features

-   **Artisanal Menu**: Curated selection of high-quality meals including our signature Fried Yam and Jollof Fiesta.
-   **Seamless Navigation**: Fast, responsive React-based interface.
-   **Admin Dashboard**: Real-time sales tracking, inventory management, and order status monitoring.
-   **Community Engagement**: Integrated partner inquiry system for catering and collaborations.

## Technology Stack

-   **Frontend**: React 19, Vite, Tailwind CSS 4.
-   **Animations**: Motion (Framer Motion).
-   **Icons**: Lucide React.
-   **Styling**: Modern Design tokens with Inter and Space Grotesk typography.

## Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or later)
-   `npm` or `yarn`

### Installation

1.  Clone the repository:
    ```bash
    git clone [your-repo-url]
    cd crunchmasters
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Configure environment:
    ```bash
    cp .env.example .env.local
    # Edit .env.local with your configuration
    ```

4.  Run development server:
    ```bash
    npm run dev
    ```

## Project Structure

-   `src/components`: Reusable UI components.
-   `src/pages`: Main application screens (Home, Menu, Admin, etc.).
-   `src/lib`: Utility functions and shared logic.
-   `src/index.css`: Global styles and design system tokens.
